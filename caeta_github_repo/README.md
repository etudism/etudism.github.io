# CAETA PLATEAU GitHub Pages版

このフォルダをそのまま GitHub リポジトリに置けば、GitHub Pages で公開できます。

## 構成
- `index.html` : 本体
- `.nojekyll` : GitHub Pages でそのまま配信するための設定

## 使い方
1. GitHub でリポジトリを作成
2. このフォルダの中身をアップロード
3. GitHub Pages を有効化
   - Settings
   - Pages
   - Build and deployment
   - Source を `Deploy from a branch`
   - Branch を `main` / `/ (root)`
4. 公開URLを開く

## 注意
- まずは周辺建物レイヤーだけを読む最小版です
- terrain / water は入れていません
- 既存 UI は変更せず、PLATEAU 建物表示だけを追加する前提の簡易版です
